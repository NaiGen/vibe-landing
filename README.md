# Шаблон лендинга

Технический каркас сайта на Next.js: приём заявок, SEO, аналитика, юридические
страницы — всё уже написано и работает.

**Дизайна и секций здесь нет намеренно.** Их ты делаешь сам — это твой сайт,
а не копия чужого. Шаблон снимает с тебя настройку окружения, чтобы лимиты
ушли на дизайн и содержание, а не на конфиги.

## Что нужно

- Node.js 24 или новее — [nodejs.org](https://nodejs.org)
- pnpm: `npm install -g pnpm`
- Аккаунт GitHub и аккаунт Vercel

## Быстрый старт

1. Нажми **Use this template** → **Create a new repository**
2. Склонируй свой новый репозиторий
3. В папке проекта:

```bash
pnpm install
pnpm setup     # 5 вопросов, заполнит lib/site.ts
pnpm dev
```

Открой http://localhost:3000 — увидишь, что осталось сделать.

## Как работать

1. Заполни `brief.md` — это источник правды по проекту. Заполнив один раз,
   ты больше не пересказываешь Claude, чем занимается компания и какой у тебя
   телефон: он читает файл сам.
2. Скажи Claude `/brand-init` — он перенесёт данные в `lib/site.ts`.
3. `pnpm test` — guard проверит, что заглушек не осталось.
4. Удали `app/page.tsx` и собирай свой лендинг.

## Что внутри

| Путь | Что это |
| --- | --- |
| `brief.md` | бриф проекта |
| `lib/site.ts` | вся конфигурация сайта — правишь только его |
| `lib/lead/` | приём заявок: схема, отправка, защита от спама |
| `components/lead/` | форма и модалка |
| `components/seo/` | разметка для поисковиков |
| `components/analytics/` | счётчики и трекер кликов |
| `.claude/skills/` | команды для Claude — работают сразу |

## Команды

| Команда | Что делает |
| --- | --- |
| `pnpm dev` | запустить разработку |
| `pnpm test` | тесты и проверка заглушек |
| `pnpm lint` | проверка типов |
| `pnpm check-brief` | что осталось заполнить в брифе |
| `pnpm build` | сборка |

## Заявки

Пока не заполнены `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`, форма работает
в **демо-режиме**: отвечает успехом и печатает заявку в консоль. Это нормально —
бота подключают в конце. Чтобы уводить заявки в почту или CRM, положи свой файл
рядом с `lib/lead/providers/telegram.ts`.

## Юридические страницы

Тексты политики конфиденциальности и оферты — **шаблонные**. Перед запуском
сайта их обязан проверить юрист. Мы не несём ответственности за их содержание.

## Публикация

Скажи Claude `/deploy` — он проведёт по шагам: Vercel, переменные окружения,
домен, проверка на бою.
