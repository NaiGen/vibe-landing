# Добавление языков к лендингу

Этот шаблон изначально одноязычный. Апгрейд делается на месте —
не нужно клонировать другой шаблон и терять работу.

1. Предупреди автора: переводы — это его работа, модель не должна
   выдумывать казахский или английский текст. Спроси, есть ли переводы.
2. Установи `next-intl`.
3. Создай `lib/i18n/routing.ts`:
   `defineRouting({ locales, defaultLocale: 'ru', localePrefix: 'as-needed',
   localeDetection: false, alternateLinks: false })`.
   Основной язык идёт без префикса в адресе.
4. Создай `lib/i18n/request.ts`. Обязательно: **всегда** грузи `messages/ru.json`
   как основу и накладывай запрошенный язык поверх, ключ за ключом.
   Иначе непереведённый ключ уронит страницу вместо того,
   чтобы показать русский текст.
5. Перенеси `app/*` в `app/[locale]/*`, кроме `api/`, `robots.ts`,
   `sitemap.ts`, `manifest.ts`.
6. Вынеси строки из `lib/content/*.ts` в `messages/<locale>.json`.
7. `alternates.languages` в метадате — только для языков,
   у которых перевод реально существует.
8. Обнови `app/sitemap.ts`: каждая страница × каждый язык.
9. `pnpm lint && pnpm build`.
