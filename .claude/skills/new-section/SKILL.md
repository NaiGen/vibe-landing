# Новая секция лендинга

1. Уточни у автора назначение секции, если оно неочевидно из запроса.
2. Возьми содержание из `brief.md` — раздел «Контент». Не выдумывай
   услуги, цены и отзывы: если их нет в брифе, спроси.
3. Создай файл текстов `lib/content/<секция>.ts` с типизированной константой.
   Весь пользовательский текст — только здесь, в JSX его быть не должно.
4. Создай компонент `components/sections/<секция>.tsx`. Ограничения:
   - не длиннее 150 строк
   - семантическая разметка: `<section>`, заголовок нужного уровня
   - контакты только через `SITE`
   - кнопка заявки — `openLeadModal('<имя секции>')`
5. Если секция — FAQ: серверный `<details>`, не `useState`. Массив вопросов
   положи в `lib/content/faq.ts` и там же, в компоненте секции, отрендери
   `<FaqJsonLd items={FAQ} pageUrl={absoluteUrl('/')} />` из
   `@/components/seo/json-ld` — ровно из того же массива, из которого
   рендерятся `<details>`. Не дописывай FAQ в `buildGraph()`:
   тот граф общий для всех страниц.
6. Подключи секцию в `app/page.tsx`.
7. Запусти `pnpm lint`.
