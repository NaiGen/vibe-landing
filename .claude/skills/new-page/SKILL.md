# Новая страница

Делается одним проходом — все шаги обязательны, пропуск любого
означает страницу без индексации или без перелинковки.

1. Уточни адрес страницы (латиницей, без хвостового слеша) и её назначение.
2. Создай `app/<путь>/page.tsx`.
3. Добавь `export const metadata` или `generateMetadata`:
   - `title` — до 60 символов, без названия компании (его добавит шаблон)
   - `description` — 120–160 символов
   - `alternates: { canonical: absoluteUrl('/<путь>') }`
4. Тексты вынеси в `lib/content/<страница>.ts`.
5. Если страница индексируется — добавь путь в массив `paths`
   в `app/sitemap.ts`. Страницу с `robots: { index: false }`
   в sitemap не добавляй.
6. Поставь ссылку на страницу хотя бы с одной существующей страницы —
   страница без входящих ссылок плохо индексируется.
7. Если у страницы есть FAQ — отрендери на ней
   `<FaqJsonLd items={FAQ} pageUrl={absoluteUrl('/<путь>')} />`.
8. Запусти `pnpm lint`.
