# Публикация

**Проект в Vercel уже есть.** Его завёл сам автор сайта на шаге 2 быстрого
старта — Import Git Repository, до первого разговора с Claude, — и с тех пор
каждый пуш в `main` пересобирает сайт автоматически. Импортировать второй
раз нечего: второй проект на тот же репозиторий даст второй адрес,
две сборки на каждый коммит и путаницу с доменом.

Если проекта всё-таки нет (автор пришёл не этим путём) — тогда и только
тогда попроси его сделать шаг 2: <https://vercel.com/new> → вход через
GitHub → Import Git Repository → Deploy. Настраивать нечего, Next.js
Vercel узнаёт сам. Это единственное действие в этом скиле, которое
за автора не сделать.

1. **Проверка перед публикацией.** Прогони `/seo-check`. Не публикуй
   с красным guard-тестом: заглушка в конфиге уедет в канонические адреса
   и разметку для поисковиков.
2. **Режим индексации.** Это делает эта команда и только она: в `lib/site.ts`
   переключи `SITE.indexable` с `'private'` на значение из брифа
   («Индексировать сайт в поиске?», раздел 3): `да` → `'public'`,
   `нет` → `'ads-only'` (пускает AdsBot-Google, поиск — нет). Поле пустое —
   спроси одним вопросом в чате и запиши ответ обратно в бриф.
   Пока стоит `'private'`, `robots.txt` закрывает сайт, `sitemap.xml` пуст,
   а Lighthouse ставит низкий балл по SEO — это настройка, а не поломка.
3. **Переменные окружения** в Vercel (Settings → Environment Variables):
   - `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` — если заявки идут в Telegram
   - `NEXT_PUBLIC_GTM_ID`, `NEXT_PUBLIC_YM_ID`, `NEXT_PUBLIC_FB_PIXEL_ID` — если есть

   Добавляет их автор мышью в интерфейсе Vercel — токены в репозиторий
   не кладут. Напомни, что после добавления нужен повторный деплой:
   в уже собранный проект переменные не подхватываются.
4. **Публикация — это пуш.** Выполни `/ship`: он гоняет проверки, коммитит
   и пушит. Vercel увидит коммит и соберёт сайт сам. Дождись и скажи,
   что сборка прошла (`git log --oneline -1` плюс открывшийся адрес),
   а не «должно задеплоиться».
5. **Домен** (Settings → Domains) — добавляет автор, у Claude нет доступа
   к его аккаунту. Продиктуй по шагам:
   - **apex-домен** (`romashka.kz`) как основной;
   - `www.romashka.kz` с выбором **Redirect to** apex — канонический адрес
     сайта без `www`, шаблон собирает все ссылки именно так;
   - записи DNS у регистратора — Vercel показывает их на этом же экране.
   Домена ещё нет — сайт остаётся на адресе `*.vercel.app`, это рабочий
   адрес, а не заглушка. Купит — вернётесь к этому шагу и заодно поправите
   `SITE.domain` и `SITE.url` (или просто позовёте `/brand-init`).
6. **Проверь на бою** — сам, запросами, а не на словах:
   - `https://<домен>` открывается, сертификат валиден;
   - `https://www.<домен>` редиректится на адрес без `www`;
   - `/robots.txt` соответствует режиму `SITE.indexable`;
   - форма отправляет заявку и она доходит.
7. **Если сайт публичный** — добавь его в Google Search Console и отправь
   `sitemap.xml`. Доступ к консоли у автора: скажи, куда нажать.
