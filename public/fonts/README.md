# Шрифт для OG-картинки (`og.ttf`)

## Что это

`og.ttf` — шрифт, которым `app/opengraph-image.tsx` рисует превью 1200×630 для
соцсетей и мессенджеров. Использует его только этот файл, через `readFile` +
мемоизацию на модуле (см. комментарий в `app/opengraph-image.tsx`).

- **Гарнитура:** Golos Text, начертание Bold (`wght=700`).
- **Автор / правообладатель:** The Golos Text Project Authors
  (https://github.com/googlefonts/golos-text).
- **Лицензия:** SIL Open Font License, Version 1.1. Полный текст лежит рядом —
  `public/fonts/OFL.txt`, взят без изменений из репозитория `google/fonts`
  (`ofl/golostext/OFL.txt`). OFL прямо требует, чтобы уведомление об авторских
  правах и текст лицензии сопровождали каждую копию шрифта — поэтому файл
  лицензии коммитится вместе со шрифтом и должен доезжать до любого форка
  шаблона.
- **Источник:** оригинальный variable-файл `GolosText[wght].ttf` взят из
  `https://github.com/google/fonts/blob/main/ofl/golostext/GolosText%5Bwght%5D.ttf`.

## Почему не сам variable-файл

`next/og` (Satori) ненадёжно работает с variable-шрифтами — поэтому нужен
статический TTF. Google Fonts публикует Golos Text только как variable, так что
статика получена инструментом `fonttools`, а не скачана готовой:

```bash
# 1. Зафиксировать единственную ось wght в одно значение 700 —
#    fonttools сам убирает fvar/gvar/HVAR/VVAR, результат — обычный статический TTF.
python3 -m fontTools.varLib.instancer \
  GolosText\[wght\].ttf wght=700 -o golostext-static700.ttf

# 2. Сжать до нужного набора символов (subset, см. ниже).
python3 -m fontTools.subset golostext-static700.ttf \
  --output-file=og.ttf \
  --unicodes="U+0020-007E,U+00A0-00FF,U+0100-017F,U+0400-04FF,U+2000-206F,U+20A0-20BF,U+2116" \
  --layout-features='*' --glyph-names --symbol-cmap --legacy-cmap \
  --notdef-glyph --notdef-outline --recommended-glyphs \
  --name-IDs='*' --name-legacy --name-languages='*' --no-recalc-bounds
```

Проверка, что `fvar` действительно отсутствует (шрифт статический):

```bash
python3 -c "
from fontTools.ttLib import TTFont
print('fvar' in TTFont('public/fonts/og.ttf'))  # должно быть False
"
```

Текущий `og.ttf` — 59 012 байт, далеко от ориентира в 500 КБ.

## Какие символы обязаны быть в этом шрифте — сверяй при любой замене

Если шрифт когда-нибудь понадобится заменить (другая гарнитура, обновление,
форк под другой рынок), новый файл обязан пройти все пункты ниже. Пропуск
любого — это квадраты в чужих превью, которые никто не заметит до продакшена
(история с ₸ — ровно этот случай: сам шрифт-кандидат физически не содержал
глиф, никакой subset это не чинит).

- **Русская кириллица, включая Ё/ё** — без этого дублирования вся суть шрифта
  теряется, а «Ё» пропускают чаще всего.
- **Казахские буквы** Ә Ғ Қ Ң Ө Ұ Ү Һ І (и строчные ә ғ қ ң ө ұ ү һ і) — шаблон
  рассчитан на казахстанский рынок.
- **Блок Currency Symbols (U+20A0–U+20BF) целиком**, и внутри него обязательно
  ₸ (U+20B8, тенге) — `SITE.description` свободное поле, и цену в тенге
  ученик укажет с высокой вероятностью. Заодно проверить ₽ и ₴ — шаблон могут
  форкнуть под Россию или Украину.
- **«Ёлочки»** « » (U+00AB/U+00BB) и **длинное тире** — (U+2014) — стандартная
  русская пунктуация для кавычек и разрывов в описаниях услуг.
- Базовая латиница и цифры (обычно есть в любом шрифте по умолчанию, но
  стоит перепроверить явно).

Быстрая проверка нового кандидата целиком:

```bash
python3 -c "
from fontTools.ttLib import TTFont
f = TTFont('путь/к/новому-шрифту.ttf')
cmap = f.getBestCmap()

checks = {
    'кириллица (Ж)': ord('Ж') in cmap,
    'Ё/ё': 0x401 in cmap and 0x451 in cmap,
    'казахские буквы': all(ord(ch) in cmap for ch in 'ӘҒҚҢӨҰҮҺІәғқңөұүһі'),
    'тенге ₸': 0x20B8 in cmap,
    'рубль ₽': 0x20BD in cmap,
    'гривна ₴': 0x20B4 in cmap,
    'ёлочки « »': 0xAB in cmap and 0xBB in cmap,
    'длинное тире —': 0x2014 in cmap,
    'статический (fvar отсутствует)': 'fvar' not in f,
}
for label, ok in checks.items():
    print(('OK ' if ok else 'НЕТ ') + label)
"
```

Если хотя бы один пункт «НЕТ» — шрифт не подходит, искать другой или
собирать статический инстанс из variable-версии, как описано выше.

## Состав текущего subset (486 кодпоинтов)

Диапазоны, включённые в `og.ttf`:

- `U+0020–007E` — базовая латиница (ASCII)
- `U+00A0–00FF` — Latin-1 Supplement (диакритики, неразрывный пробел, «ёлочки»)
- `U+0100–017F` — Latin Extended-A
- `U+0400–04FF` — весь блок Cyrillic (русская кириллица с Ё/ё и казахские
  буквы лежат внутри этого же блока — отдельно добавлять не нужно)
- `U+2000–206F` — General Punctuation (тире, многоточие, кавычки-лапки)
- `U+20A0–20BF` — весь блок Currency Symbols (в самом Golos Text реально
  присутствуют €, ₴, ₸, ₽ — остальные коды блока в этом шрифте физически
  отсутствуют, это ограничение гарнитуры, а не subset)
- `U+2116` — № (номерной знак)
